# Обзор станции

## Концепция

Никакого агента на компьютерах — только браузер.
Каждый компьютер открывает браузер на адресе Vue-приложения.
Взаимодействие с сервером происходит через REST API.

## Флоу

1. Браузер открывает Vue-приложение
2. Экзаменатор вводит пароль станции → `POST /api/exam/unlock`
3. Станция разблокирована, кандидат может войти
4. Кандидат вводит `accessCode` → `POST /api/exam/login`
   - Если `IsAllowed = false` → 403 Forbidden
   - Если `BlockedUntil > UtcNow` → 403 с сообщением "Доступ заблокирован до {дата}"
5. `POST /api/exam/start` → создаётся попытка, возвращается список секций
6. Кандидат выбирает секцию → `POST /api/exam/section/start`
7. Отвечает на вопросы → `POST /api/exam/section/answer`
8. Завершает секцию → `POST /api/exam/section/submit`
9. После сдачи всех секций — `POST /api/exam/submit` → возвращается результат (уровень A1–B2)

## Безопасность

- Станция разблокируется паролем из конфигурации (`ExamSettings__AccessPassword`)
- Кандидат идентифицируется только по `accessCode` — JWT не используется
- Заблокированный или лишённый доступа кандидат не может начать экзамен
