# Обзор станции

## Концепция

Никакого агента на компьютерах — только браузер.
Каждый компьютер открывает браузер на адресе сервера.
Все обновления автоматически получают все 50 машин.

## Флоу

Компьютер включается
Браузер открывает главную страницу
Станция подключается к SignalR хабу
Регистрирует свой номер
Ожидает команды от сервера
Кандидат вводит ExamCode
Система проверяет ExamCode + StationNumber
Открывается страница теста


## Безопасность

- Каждая станция имеет уникальный Token
- Token хранится в `.env` на каждом компьютере
- Без валидного Token — подключение отклоняется
- JWT токен выдаётся после авторизации станции
