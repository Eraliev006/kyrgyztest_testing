# Роли в системе

## Разделы

- [Обзор ролей](overview.md)

## Роли

| Роль | Описание |
|------|----------|
| SuperAdmin | Полный доступ, управление пользователями и конфигурацией |
| Director | Управление организациями, результатами, пользователями (кроме SuperAdmin/Director) |
| Admin | Регистрация кандидатов, управление доступом |
| Examiner | Базовая роль для экзаменаторов |
| Expert | Управление вопросами, темами и медиафайлами |
