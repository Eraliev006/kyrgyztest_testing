# Обзор ролей

## Администратор

- Регистрирует кандидатов через систему или сканирование паспорта
- Назначает кандидата на свободный компьютер
- Активирует станции (выдаёт токены)
- Переносит сессию при сбое
- Видит все 50 компьютеров в реальном времени

## Кандидат

- Приходит с паспортом
- Получает ExamCode после регистрации
- Садится за назначенный компьютер
- Вводит ExamCode → проходит 4 секции теста
- Получает результат и сертификат

## Проверяющий

- Проверяет секцию Writing вручную
- Выставляет баллы

## Директор

- Просматривает статистику экзаменов
- Видит результаты по категориям
- Скачивает отчёты
