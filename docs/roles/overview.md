# Обзор ролей

## SuperAdmin

- Полный доступ ко всем эндпоинтам
- Создаёт директоров и администраторов
- Управляет конфигурацией секций и вариантами теста
- Создаётся автоматически при старте (`superadmin` / `admin123`)

## Director (Директор)

- Создаёт и управляет организациями
- Создаёт пользователей с ролями ниже Director (не может создать SuperAdmin/Director)
- Просматривает результаты и статистику по организациям
- Управляет вариантами теста и конфигурацией секций
- Блокирует и лишает доступа кандидатов

## Admin (Администратор)

- Регистрирует кандидатов и открывает им доступ к экзамену
- Загружает фото кандидатов
- Блокирует и лишает доступа кандидатов
- Ищет кандидатов по ИНН или коду доступа

## Examiner (Экзаменатор)

- Присутствует в системе для разграничения прав
- Не имеет специфических эндпоинтов в текущей версии

## Expert (Эксперт)

- Создаёт, редактирует и удаляет вопросы
- Управляет темами вопросов (Topics)
- Загружает аудиофайлы для вопросов типа Listening

## Кандидат

Кандидат не является пользователем системы и не проходит JWT-аутентификацию. Вместо этого:

- Получает `accessCode` после регистрации (формат `YYYYMMDD-NNNN`)
- Вводит код на станции → `POST /api/exam/login`
- Проходит секции теста в любом порядке
- Получает результат с уровнем A1–B2 после сдачи
