## Аутентификация

Большинство эндпоинтов требуют JWT-токен в заголовке:

```
Authorization: Bearer <token>
```

Токен получается через `POST /api/auth/login`.

## Формат ошибок

```json
{ "message": "Описание ошибки" }
```

Коды: `400` — валидация, `401` — не авторизован, `403` — нет прав, `404` — не найден.
